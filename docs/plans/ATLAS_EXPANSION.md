# Atlas expansion plan

[English](ATLAS_EXPANSION.md) · [Русский](../ru/plans/ATLAS_EXPANSION.md) · [Coverage audit](../research/ATLAS_COVERAGE_AUDIT.md) · [Learning roadmap](../LEARNING_ROADMAP.md)

Plan date: **2026-10-05**. This is the implementation backlog for the research and learning expansion, subordinate to the repository-wide [roadmap](../ROADMAP.md) and [methodology](../METHODOLOGY.md). Priorities express dependencies and value, not promised dates. The initial P0 documentation scope was extended to **all identified content work**: source corrections, questions where provenance permits, answers, primary reading and explanation/case checklists. Python exercises, executable labs, project implementation and an AI evaluator are **deferred by the maintainer**. No new schemas or CLI are included.

The two canonical tracks remain Engineering and Leadership. Focused routes, responsibility branches and original curriculum cases do not become new tracks or inflate the question bank. Published questions still require interview evidence; radar-generated questions still follow the existing provenance contract. Appearing in a guide does not give an editorial drill either provenance category.

## Work allocation and review

For future work in this expansion, use **gpt-6.1-sol** for engineering implementation and routine code checks, **gpt-6-astra** for complex public prose, semantic audit and independent final content review, and **gpt-6-luna** for bounded extraction and mechanical checks. These are task assignments, not claims about comparative prices or benchmark capability. Use no more than **four concurrent agents**, and parallelise only disjoint files or read-only tasks. Keep dependencies and integration sequential.

The final content reviewer must be a separate session from every author/editor of the reviewed public prose. A self-check or a second label for the same session does not qualify. Follow the active environment's flagship requirement; a missing required model blocks that task rather than being relabelled. Preserve prior Claude and other authors' records. Actual model/session identities, source-check details and review evidence belong in private working records, not invented public authorship claims.

Every implementation handoff runs the checks required by [CONTRIBUTING](../../CONTRIBUTING.md): lint/format, tests, generated-content check, strict site build, and privacy checks for worktree, index and history. Stage explicit paths only. Scope changes, unresolved source gaps and failed gates remain visible. The maintainer separately decides whether to publish or release a reviewed result.
